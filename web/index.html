One triad per chord, all on the same three adjacent strings. The first chord (or the key's chord) is the anchor; the rest keep your hand moving as little as possible.

    
A triad has room for three notes, so four-note chords lose one. 6, m6, 7, maj7, m7, and add9 drop the 5th: A7 plays A, C#, G. In m7b5 and dim7 the flat 5th is the point, so the 3rd goes instead: Bm7b5 plays B, F, A.

Build guitar chord charts, scale charts, and neck diagrams as SVG or PNG. Everything renders right here in your browser; nothing is uploaded.


      

        

          
Pick a tab

          

            
Chord
One chord chart.

            
Chord Sheet
A grid of chord charts, one row per chord.

            
Triads
Find triad voicings for a progression, close together on three strings.

            
Scale
A five-fret box with any number of notes per string.

            
Neck
A long stretch of the fretboard, drawn sideways.

            
File
Open, paste, or edit a FretCharts file directly.

          

        


        

          
Write a chord

          
One character per string, low E first. x for muted strings, 0 for open strings, or a number for the fret. x02220 is A major; 320003 is G.

          
Frets 10 and up go inline (x8101098) or, if you'd rather, with spaces or dashes between strings (x-8-10-10-9-8).

          
Strings are numbered 6 (low E) to 1 (high E) everywhere else: string fields, labels, and stylesheet classes. Or customize the strings and tunings for other instruments.

        


        

          
Style it

          
Every tab has a Stylesheet field. Start from a theme, or write CSS against classes like chord-dot and chord-string-6. Change the shape of notes. SVG defs holds gradients and patterns, and Transpose shifts every note up or down the neck.

        


        

          
Save and share

          
FretCharts File downloads what you've built as a .yaml file. Open it again from the File tab to pick up where you left off. Copy link puts the whole chart in a link instead.

          
The same files render from the command line: npm install -g github:rawg/fretcharts. See the README for the CLI and every option.
